# Satellite Image Prediction Using Deep Learning

## Project Overview
This project uses Deep Learning techniques to analyze and classify satellite images. The model is trained on satellite image datasets and predicts image categories with high accuracy.

## Features
- Satellite image classification
- Deep learning-based prediction
- User-friendly web interface
- Image upload and prediction
- Fast and accurate results

## Technologies Used
- Python
- TensorFlow / Keras
- MobileNet
- Flask
- HTML
- CSS
- Jupyter Notebook

## Project Structure

├── static/
├── templates/
├── app.py
├── mobilenet_weights.weights.h5
├── satellitedata.ipynb
└── README.md
